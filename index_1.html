Add it to Outlook (Mac)
  1. Click Copy signature above.
  2. In Outlook go to Settings → Signatures, add a new one, and paste.
  3. Set it as the default for new messages and replies.

Outlook on the web: Settings → Mail → Compose and reply, then paste. If a pasted signature loses its layout, use the HTML code instead.
